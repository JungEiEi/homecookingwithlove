# Home Cooking with Love

"เพราะความอร่อย คือการบอกรักผ่านอาหารที่ทำด้วยใจ"

เว็บไซต์สไตล์อาหารบ้าน/เมนูทำง่าย สำหรับคนที่อยากทำอาหารอร่อยให้คนที่รักได้ทาน โดยใช้แนวคิดการนำเสนอเมนูหลากหลายแบบสวยงาม พร้อมโหมดสุ่มเมนูและหน้ารายละเอียดเมนูที่ใช้งานง่าย

## ภาพรวม

โครงการนี้เป็นหน้าเว็บแบบ Static Site ที่นำเสนอเมนูอาหารหลากหลาย เช่น

- เมนูแนะนำยอดนิยม
- เมนูที่แฟนชอบ
- เมนูประหยัด
- เมนูทำไว 15–20 นาที
- ป๊อปอัปรายละเอียดสูตรอาหาร
- ปุ่มสุ่มเมนูอาหารแบบสุ่มวันละเมนู

## คุณสมบัติ

- การออกแบบหน้าเว็บแบบ responsive สำหรับมือถือและเดสก์ท็อป
- ใช้ Tailwind CSS สำหรับการจัดรูปแบบ UI
- ป๊อปอัปแสดงรายละเอียดวัตถุดิบและขั้นตอนทำอาหาร
- ระบบสุ่มเมนูอาหารแบบโต้ตอบ
- เน้นสไตล์อาหารไทยและความอบอุ่นที่บรรยากาศบ้าน

## เทคโนโลยีที่ใช้

- HTML5
- Tailwind CSS
- Font Awesome
- JavaScript
- Google Fonts

## วิธีเปิดใช้งาน

### เปิดโดยตรง

เพียงดับเบิลคลิกไฟล์ `index.html` หรือเปิดผ่านเว็บเบราว์เซอร์

### เปิดผ่าน local server

```bash
cd homecookingwithlove
python -m http.server 8000
```

จากนั้นเปิดที่:

```text
http://localhost:8000
```

## วิธีปรับแต่ง

- แก้ไขข้อความและข้อความโฆษณาได้ในไฟล์ `index.html`
- เปลี่ยนสีและธีมได้ผ่าน Tailwind config ภายในหน้า HTML
- เพิ่มเมนูใหม่ได้โดยเพิ่ม card และ modal script ให้สอดคล้องกับโครงสร้างเดิม
